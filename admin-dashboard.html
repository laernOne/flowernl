Закрита адмін-панель

Керування товарами та замовленнями

Панель адміністратора працює через localStorage, захищена клієнтською перевіркою логіна і пароля та не виводиться у публічній навігації сайту.

Навчальна статична реалізація: дані зберігаються у браузері, а облікові дані адміністратора задаються у файлі config/admin-config.js.

Службові дії

Цей блок потрібен для демонстрації керування початковими даними проєкту.

Зображення, додані адміністратором, зберігаються у localStorage як Data URL. Для стабільної роботи бажано використовувати оптимізовані файли до 2 МБ.

Додавання товару

Підтримуються JPEG, PNG, WebP, GIF, SVG. Файл зберігається у браузері як Data URL.

Демонстраційний сайт магазину квітів з Нідерландів, реалізований засобами HTML, CSS і JavaScript.
