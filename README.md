# FlowerNL

FlowerNL – адаптивний статичний сайт магазину квітів з Нідерландів, реалізований засобами HTML, CSS і JavaScript.

## Запуск

1. Розпакуйте архів.
2. Відкрийте `index.html` у браузері.
3. Сервер, Python, PHP або SQLite не потрібні.

## Адмін-панель

Адмін-панель не має кнопки в публічному меню сайту. Вхід відкривається тільки за прямим посиланням:

`admin-login.html`

Після входу відкривається:

`admin-dashboard.html`

Дані адміністратора задаються у файлі:

`config/admin-config.js`

Стандартні дані для входу:

- логін: `admin`
- пароль: `Admin123!`

У конфігураційному файлі зберігається SHA-256 хеш пароля. Для зміни пароля потрібно замінити `username` і `passwordHash` у файлі `config/admin-config.js`.

## Функціонал

- адаптивна верстка для мобільних екранів, планшетів і десктопів;
- каталог товарів;
- пошук, фільтрація і сортування;
- кошик;
- оформлення замовлення;
- збереження даних у `localStorage`;
- закритий вхід до адмін-панелі;
- додавання, редагування і видалення товарів;
- завантаження зображень товарів у форматах JPEG, PNG, WebP, GIF, SVG;
- перегляд і зміна статусів замовлень;
- очищення замовлень і відновлення початкового каталогу.

## Обмеження навчальної статичної реалізації

Проєкт не використовує серверну частину, тому авторизація є демонстраційною і виконується на стороні браузера. Для реального комерційного використання потрібно додати серверну автентифікацію, базу даних, захист сесій і серверне зберігання файлів.
